# 知栈 · 判断库（Sourcecast Judgment Library）

一条每天自动起跑的 AI 技术播客流水线，把每期最后沉淀下来的「判断」抽出来，
做成可检索、可收藏、可导出的资料库网页。

- 39 期节目 / 50 条判断（全部逐字摘自原稿）/ 71 个讲过的开源仓库 / 8 期可试听
- 纯静态：无框架、无 CDN、无外链、无追踪；断网可开
- 收藏存在浏览器 localStorage，不上传任何服务器

## 结构

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构 |
| `styles.css` | 设计系统（纸质底 / 宋体标题 / 墨绿强调色，含深色模式） |
| `app.js` | 渲染、搜索、筛选、收藏、导出、抽屉 |
| `data.js` | 由构建脚本生成的数据（`window.LIB`） |
| `media/` | 8 段 96 秒试听片段（云端语音合成，48 kbps 单声道） |

数据来自每期节目的页面 Markdown，构建脚本：`scripts/build_library_data.py`
（人工精修层：`data/curated.json`，判断逐字摘录，不改写）。

## 说明

音频为 AI 合成，非真人录音；已做脱敏（去掉本机路径、第三方人名），
含第三方音色的期次只放文字不放试听。
